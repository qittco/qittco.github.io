## About This Project

Rather than starting with a template or framework, I'm building my portfolio from the ground up.

The idea is simple: **learn, build, improve, and document the process.**

I'm starting with semantic HTML, focusing on accessibility, meaningful content, and a solid foundation before introducing visual design or interactivity.

## Development Roadmap

- [x] **Phase 1 — HTML:** Build the initial website with semantic HTML.
- [ ] **Phase 2 — CSS:** Introduce responsive layouts, typography, and a unique visual identity.
- [ ] **Phase 3 — JavaScript:** Add thoughtful interactions and dynamic features.
- [ ] **Phase 4 — Projects:** Showcase applications, experiments, and technical case studies.
- [ ] **Phase 5 — Beyond:** Continue expanding the website as my skills and projects evolve.
